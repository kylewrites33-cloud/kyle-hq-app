Your HQ data lives in your private personal-data repo. Paste a GitHub key here once on each device. It stays on this device only.

  1. Open GitHub's new key page.
  2. Name it "Kyle HQ app" and set an expiry.
  3. Under Repository access, choose Only select repositories and pick personal-data.
  4. Under Permissions, set Contents to Read and write.
  5. Tap Generate, copy the key and paste it here.
